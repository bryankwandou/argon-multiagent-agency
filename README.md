# Argon Multi-Agent Agency — Gemini 4 Argon (High) Command Floor

Autonomous Multi-Agent Agency Workstation combining:
- **2.5D Isometric Agency Office Floor**: Real-time interactive office floor with 10 specialized agents (`ORCH-01` through `SRE-10`), pathfinding between Executive Suite, Bullpen, Breakroom, Reception, Security/SRE Wing, and Council Conference Room, plus live speech callout bubbles.
- **Gemini 4 Argon (High) Live Multi-Agent Chat & Task Delegator**: Decomposes complex directives into specialized agency sub-tasks with support for both built-in autonomous synthesis and live Google Gemini API streaming.
- **OpenAI Dots DAG Wires & Telemetry Sidebar**: Real-time `PRODUCTION` and `PREVIEW` Cloud Run environments, `WORKFORCE` telemetry, `WIRES` moment bars, and `FLOOR CHATTER` stream.
- **Grok Heavy Multi-Agent Council**: Parallel 10-agent cross-critique, Red-Team verification, and consensus voting.
- **Centralized Design Tokens & Bilingual Localization**: Full Dark/Light mode (`src/styles/tokens.css`) and Bahasa Indonesia / English (`id` / `en`) localization.
